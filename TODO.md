# RayGram iOS — Feature Roadmap & TODO List

- **Версия:** 13.0
- **Текущий билд:** 35322 (Release)

## ✅ Уже реализовано (Completed)

### Брендинг и интерфейс
- [x] **Имя приложения «RayGram»** на домашнем экране iOS (`CFBundleDisplayName = "RayGram"` во всех локализациях).
- [x] **Кастомная иконка приложения** в стиле ray-desk (обновлённый увеличенный логотип, нативный iOS 18 Composer Icon `.icon` + ассеты `.xcassets` и `alticon`).
- [x] **Экран настроек «RayGram»** в основном меню настроек Telegram.

### Приватность и «Призрак» (Ghost Mode)
- [x] **Скрытие статуса прочтения сообщений** (Hide Read Receipts — блокировка `readHistory`).
- [x] **Скрытие просмотра историй** (Hide Story Views).
- [x] **Скрытие статуса набора текста** (Hide Typing Status — блокировка typing и recording audio/video).

### Защита от удаления сообщений и медиа (Anti-Recall)
- [x] **Сохранение удалённых сообщений** в локальной базе данных SQLite (Save Deleted Messages).
- [x] **Нативная векторная иконка корзины Telegram** для удалённых сообщений рядом со временем сообщения (размер увеличен на 10% для гармоничного отображения).
- [x] **Тумблер пометки удалённых сообщений** (Mark with Trash Icon — вкл/выкл отображения корзины).
- [x] **Сохранение самоуничтожающихся фото и видео** (таймер не сжигает медиа, запрет на удаление).
- [x] **Полноразмерный просмотр сохранённых одноразовых медиа** (исправлен баг перехода к первому фото в переписке).
- [x] **История редактирования сообщений (Message Edit History)**: сохранение предыдущих версий текста в локальной базе Postbox при редактировании сообщений собеседником, красивый просмотр оригиналов и предыдущих версий в контекстном меню сообщения по долгому нажатию с копированием по тапу.
- [x] **Тумблер сохранения истории изменений** (Save Edited Message History в настройках RayGram).
- [x] **Отображение Telegram ID в профиле пользователя** (между номером телефона и юзернеймом в нативном стиле `ID 17319391793`), а также в профилях каналов и групп, с копированием по тапу и вызовом контекстного меню.

### Обход ограничений (Bypass Restrictions)
- [x] **Обход защиты от копирования/пересылки** (Bypass Content Protection: копирование, скриншоты, пересылка из каналов с `noforwards`).

### Чистый интерфейс и блокировка рекламы (Clean UI & AdBlock)
- [x] **Блокировка официальной рекламы Telegram** с мгновенным скрытием рекламных блоков при переключении тумблера (Hide Sponsored Messages).
- [x] **Скрытие блока «Похожие каналы»** при подписке на канал (Hide Similar Channels).
- [x] **Отключение перехода в следующий канал свайпом вверх** (Disable Jump to Next Channel).

### Удобство и звонки (QoL)
- [x] **Подтверждение перед звонком** (Confirm Before Calling для голосовых и видеовызовов).
- [x] **Точные секунды в таймстемпах** (Show Seconds in Timestamps — формат HH:MM:SS).

### Подарки и визуальные эффекты (Gifts & Visuals)
- [x] **Система фейковой отправки и получения подарков (Visual Fake Gifts)**:
  - Отправка любого реального NFT-подарка в чат по ссылке или slug (например, `https://t.me/nft/MightyArm-1486`).
  - Поддержка отправки стандартных Star Gifts из каталога Telegram при пустом поле ссылки.
  - Выбор отправителя: «От меня» (исходящий подарок) или «От собеседника» (входящий подарок от контакта).
  - Опциональная текстовая подпись к подарку.
  - 100% аутентичный нативный пузырь подарка в чате: анимированная 3D-модель, уникальный градиентный фон (backdrop), символы/паттерн, номер коллекционного подарка.
  - Открытие интерактивного 3D просмотрщика `GiftViewScreen` при тапе на подарок (вращение 3D-модели, атрибуты, редкость, дата, получатель и отправитель).
  - Кнопка «✨ Отправить фейк подарок» в меню отправки подарков (`GiftOptionsScreen`).
  - Тумблер «Enable Fake Gifts» в настройках RayGram.

## ⏳ Запланировано к реализации (Backlog / Planned)

### 1. Приватность и скрытность (Privacy & Stealth)
- [ ] **Локальный Ghost Mode с ручной отправкой прочтения** (кнопка «Пометить прочитанным» в контекстном меню чата / свайпом). *(AyuGram)*
- [ ] **Скрытие статуса «В сети» (Online)** без потери возможности видеть статус собеседников. *(AyuGram)*
- [ ] **Скрытие времени последнего захода (Last Seen)** с сохранением видимости времени других пользователей. *(AyuGram)*

### 2. История сообщений и сохранение медиа (History & Storage)
- [ ] **Сохранение видеосообщений («кружочков») и голосовых в Галерею / Файлы** в один тап через контекстное меню. *(exteraGram / Cherrygram)*
- [ ] **Сохранение удалённых медиа в отдельное скрытое локальное хранилище**. *(Cherrygram)*

### 3. Обход цензуры и ограничений платформы (Censorship Bypass)
- [ ] **Обход цензуры iOS (Sensitive Content Restriction Bypass)**:
  - Разблокировка каналов с плашкой «This channel can't be displayed on your device due to copyright / pornography / local laws».
  - Открытие запрещённых Apple каналов напрямую через `ignoreSensitiveContentRestrictions`. *(Cherrygram / Nicegram)*

### 4. Интерфейс и минимализм (UI & Customization)
- [ ] **Скрытие панели «Истории» (Stories)** над списком чатов. *(exteraGram / Cherrygram)*
- [ ] **Скрытие блока реакций под сообщениями** для более компактного отображения. *(exteraGram)*
- [ ] **Компактный список чатов** (опциональное скрытие аватарок или уменьшенная высота строк). *(exteraGram)*
- [ ] **Отображение DC** в профиле пользователя и канала по тапу. *(AyuGram / Cherrygram)*

### 5. Удобство переписки и чатов (Chat Tools & QoL)
- [ ] **Пересылка сообщений без автора (Forward without quote)** в один тап прямо из меню пересылки. *(Cherrygram / exteraGram)*
- [ ] **Быстрое удаление собственного сообщения свайпом**. *(exteraGram)*
- [ ] **Кастомное действие по двойному тапу** (ответ / копирование / перевод вместо стандартной реакции). *(Cherrygram / exteraGram)*
- [ ] **Встроенный переводчик текста сообщений** без ограничений. *(Cherrygram)*
- [ ] **Использование системной камеры iOS** вместо встроенного вьюфиндера Telegram. *(Cherrygram / exteraGram)*
